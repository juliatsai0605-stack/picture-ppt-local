# Windows v6 真實操作錄影｜筆電執行單

> **目的**：取得可供剪輯的 Windows v6 真實螢幕錄影，不使用假畫面、AI 模擬或 Linux 錄影冒充 Windows。現在尚無真實操作 MP4。
>
> **公開測試圖片 ZIP**：[下載 3 張原創 PNG](test-assets/%E5%85%AC%E9%96%8B%E6%B8%AC%E8%A9%A6%E5%9C%96%E7%89%87_3%E5%BC%B5.zip)（亦可在 [test-assets](test-assets/) 逐張檢視）。素材為本專案新製作的虛構簡報，與 Claude 先前準備的檔案並非同一份。

## 錄影電腦及安全前提

請使用曾能正常執行 v6 的**個人 Windows 筆電**，或另一台符合安全政策且允許執行 v6 的測試電腦。**家中桌機目前因 Windows Code Integrity／Smart App Control 阻擋未簽署 EXE，不可為錄影關閉防護。**

從正式 [v6.0.0 Release](https://github.com/juliatsai0605-stack/picture-ppt-local/releases/tag/v6.0.0) 下載 ZIP，解壓縮後執行 `slide2pptx/圖片簡報轉PPT.exe`。此為可攜版：**不需要安裝精靈，也不會自動建立桌面捷徑**。如 Windows 顯示系統安全封鎖，停止測試並記錄畫面，不要繞過防護。

## 最少操作流程

1. 在筆電下載三張公開測試圖片，解壓縮至單獨的「影片測試圖片」資料夾。
2. 關閉通知、郵件、私人帳號頁籤及其他不相關程式。檢查螢幕、下載資料夾及近期檔案不含機敏資訊。
3. **先測錄約 10 秒**：確認工具能完整捕捉「檔案總管、瀏覽器、PowerPoint」，且游標與畫面清晰；無法捕捉時改用適合的錄影工具。
4. 開始正式螢幕錄影（可連續錄 3–8 分鐘，後續再剪至約 60–90 秒）。
5. 真實展示：Release 下載 → 完整解壓縮 → EXE 啟動 → 本機網頁出現 → 匯入 3 張圖片 → 辨識文字 → 校對 → 產生 PPTX → PowerPoint 修改一段文字。
6. 最後開啟 https://juliatsai0605-stack.github.io/picture-ppt-local/ ，顯示正式下載入口。
7. 停止錄影，保留原始檔；若工具支援，輸出 MP4（H.264，建議 16:9、30 fps），原始畫面不夠 1920×1080 時**不要強制放大**。
8. 錄影完成後檢查：真實 v6、沒有隱私或機敏內容、按鈕名稱正確、文字編輯效果可見、影片可正常播放。

## 錄影軟體選擇

- **Windows 11 內建擷取工具**：可先開啟「剪取工具」並選取錄製模式，畫選桌面區域後錄製；如無法完整捕捉多個應用程式，停止並改用其他錄影方式。
- **OBS Studio（免費）**：若本機已安裝可使用「顯示器擷取」來源，指定 30 fps 錄製。建議先以 MKV 保存原始素材，再透過 OBS「檔案 → 重新封裝錄影」轉成 MP4。請先確認 OBS 官方文件與自身版本選單名稱；不要假設剪取工具或 Xbox Game Bar 一定能捕捉所有系統視窗。
- 旁白可以後製，**錄影時不用邊講話邊操作**。最重要的是畫面真實且清楚。

## 交給 ChatGPT 的素材與資訊

- 原始操作錄影（MP4；如原始錄製是 MKV，可交付 MKV）。
- 實際產生的測試 PPTX（不得包含個人或機關資料）。
- 錄製裝置 Windows 版本及 v6 是否成功啟動。
- 影片的完整時長、各步驟大致起迄時間、任何失敗情形。
- 可參考 [60 秒分鏡](VIDEO_SCRIPT.md) 與 [字幕 SRT](VIDEO_SUBTITLES_v6.srt)，正式剪輯時以錄製畫面調整字幕時間。

**交付前不得把示意動畫、單張截圖或程式碼視為已完成的 Windows 影片。**

## 筆電一鍵準備工具（2026-11-04）

已新增 [`prepare-v6-recording.ps1`](prepare-v6-recording.ps1)；其用途為在**可合法執行 v6 的 Windows 筆電**下載官方 ZIP、驗證 SHA-256、解壓縮並備好三張公開測試圖片。它會開啟素材資料夾、詢問是否啟動 EXE，**不會自動錄影或修改 Windows 安全政策**。
