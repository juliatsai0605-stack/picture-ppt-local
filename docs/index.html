Get started

下載、解壓縮，開始使用。

下載 Windows 執行版本後，依照下列步驟操作；桌面捷徑等細節以實際 v6 發行版為準。

STEP 01

下載並解壓縮

下載 v6.0.0 的 Windows ZIP（約 352 MiB）並完整解壓縮。程式原始碼 ZIP 不等於 Windows 執行版本。

STEP 02

啟動本機程式

開啟解壓縮後的 slide2pptx 資料夾，雙擊「圖片簡報轉PPT.exe」。此為免安裝可攜版，不會自動建立桌面捷徑；瀏覽器會開啟本機操作頁面。

STEP 03

上傳圖片、校對

匯入 PNG 或 JPG，點「① 辨識文字」，逐段檢查表格；重要內容請人工校正。

STEP 04

產生簡報並檢查

點「② 產生 PPT」，下載後在 PowerPoint 開啟。檢查字型、位置及背景圖像。

使用前提醒：此工具以原始圖片保留視覺效果，主要提供文字編輯能力。OCR、擦字與字型重建可能造成局部誤差；有機敏資料時，請依所屬機關資安及保密規定處理。
Questions

使用前，先知道這些。

圖片會上傳到雲端嗎？

程式設計為 Windows 本機離線執行，介面使用 127.0.0.1。此展示網站只提供說明及下載，不處理你的簡報圖片。

轉換後每個圖表都能編輯嗎？

不能。辨識的文字會重建為可編輯文字方塊；插圖、線條、圖表及其他背景元素通常仍保留為圖片。

Windows 顯示安全警告怎麼辦？

程式未經簽章，可能觸發 SmartScreen。請先確認下載來源與檔案安全性；公司或機關管理的電腦應遵循內部資安政策，不建議直接略過防護。
