- ZIP：可正常解壓縮，包含 Windows 啟動 EXE、Python 執行環境及模型檔。

## 功能

- 使用者將 PNG／JPG 圖片匯入 Windows 本機網頁操作介面。
- 辨識文字並在需要時人工校正，轉換為可編輯文字的 PowerPoint。
- 可批次匯入多張簡報圖片；最終仍須逐頁核對轉換結果。
- 圖表、線條及背景影像一般仍為圖片，**並非所有物件均可編輯**。

## 使用方式

1. 下載正式 GitHub Release 附件中的 Windows ZIP（不要下載 Source code ZIP 充當程式）。
2. 在 Windows 檔案總管選擇「解壓縮全部」，勿直接在壓縮檔內執行。
3. 進入解壓縮的 `slide2pptx` 資料夾，開啟「圖片簡報轉PPT.exe」。
4. 使用啟動後的本機網頁介面匯入圖片，依操作畫面完成文字辨識、校正及轉換。
5. 開啟產生的 PPTX，逐頁核對文字位置、字型及背景。

**此為免安裝可攜版，不含自動桌面捷徑或安裝精靈。** 無須另外安裝 Python。
